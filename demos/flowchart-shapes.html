Siren flowchart node shapes

examples/flowchart-shapes.srn — all fourteen bracket spellings Mermaid has for a node, each drawn as the figure it names, in one request-handling flowchart that uses each shape for what a flowchart has always used it for: A([Start]) the terminal, A[/Read request/] input and A[\Write log\] output, A{{Prepare}} preparation, A{Valid?} the decision, A[Parse] the process, A[(Store)] the database, A[[Render]] a predefined process, A[/Approve\] a manual operation and A[\Operator/] manual input, A((1)) an on-page connector, A(Retry) a round node, A>legacy path] the asymmetric flag, and A(((End))) the terminator. A shape's kind is what compatibility means here; its proportions belong to the theme, so these are not Mermaid's diamonds and cylinders pixel for pixel and were never meant to be. Step through it to watch each shape arrive: the id and the animation classes sit on the node's <g>, so a <path>, a <circle> and a <rect> frame all animate the same way. Toggle the theme to see the same fourteen figures repainted by tokens alone — with one exception worth knowing: --siren-node-border-radius now reaches only the rectangle and the subroutine. See the author styling demo for what style and classDef paint on these same frames, the edges and subgraphs demo for the arrow forms that join these fourteen figures and the frames they can be grouped into, and the complex showcase for every timeline verb and effect.
