Siren sequence diagram demo

Two sequenceDiagram documents. The first exercises both participant and actor declarations, all ten Mermaid message arrow forms, a title, and autonumber/autonumber off. The second exercises every control-flow block kind — loop, alt/else, opt, par/and, critical/option, break, and rect — including an alt nested inside a loop. Sequence diagrams render fully visible and static — there is no Prev/Next/Reset control here, unlike the flowchart step-reveal demos, since SirenRenderResult.controller is always null for a sequence diagram (see spec.md's Non-goals).
