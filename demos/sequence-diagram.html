Siren sequence diagram demo

Three sequenceDiagram documents. The first exercises both participant and actor declarations, all ten Mermaid message arrow forms, a title, and autonumber/autonumber off. The second exercises every control-flow block kind — loop, alt/else, opt, par/and, critical/option, break, and rect — including an alt nested inside a loop. The third puts every in-scope feature into one document, adding create/destroy participant lifecycle (both at the top level and inside a block body) and a box participant grouping. Sequence diagrams render fully visible and static — there is no Prev/Next/Reset control here, unlike the flowchart step-reveal demos, since SirenRenderResult.controller is always null for a sequence diagram (see spec.md's Non-goals).
