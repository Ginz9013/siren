Siren flowchart author styling

examples/flowchart-styling.srn — every author-styling directive a flowchart accepts, in one document: style applied to one node, classDef defining a named set, and both spellings of the apply-directive (class Parse,Resolve stage and the Layout:::stage shorthand, which is also written inside an edge line on Source and Output). Edges are addressed the way Mermaid addresses them, by declaration index: linkStyle 0, linkStyle 3,4, and linkStyle default — a fallback tier rather than a competing statement, so the first edge keeps the fallback's stroke-width while taking its own stroke. Each distinct edge color gets its own arrowhead. Render and the two terminal nodes carry a color beside their fill: the author writes color and the label carries fill, because that is what paints SVG text. Toggle the theme to see the difference an author style makes — an opaque fill stays put in either theme, which is why it now has to bring its own text color, while the translucent stage fill lets the theme through. See the complex showcase for the animation side of the same diagram kind, the node shapes demo for the fourteen figures a node can be drawn as — every one of them carrying the same siren-node-frame these directives land on, whatever element draws it — and the edges and subgraphs demo for what linkStyle reaches once an edge has a line style, two ends and a label of its own: a color there paints the label, and a stroke paints the line and its arrowhead together.
